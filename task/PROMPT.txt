从零实现一套跨安全区网络流量镜像授权模拟器。安全团队只允许经发送区和接收区双方批准的连接元数据进入对方的诊断视图。使用 Windows 原生 Python 3.12、标准库和 SQLite。输入为本地生成的合成连接描述和策略事件，无真实地址数据、抓包、套接字或外部服务。提供 apply-policy、explain、export、verify 命令。

每条连接包含不可变 ID、事件时间、源区与目的区、源与目的 IP、传输协议和目的端口，以及若干可导出字段。IPv4 与 IPv6 各自匹配同族 CIDR。策略具有安全区、负责方向（发送或接收）、对端安全区、两侧 CIDR、协议及端口闭区间、有效时间半开区间、签发机构、允许导出的字段集合。先按连接方向、地址、协议、目的端口及事件时间匹配适用策略。任一侧匹配显式拒绝，整条连接禁止导出。没有拒绝时，每个字段只在存在一个发送批准和一个接收批准且二者签发机构不同的情况下可以导出。两个方向的审批可能覆盖不同字段，必须逐字段求合法审批对，不能拼接成一份整条连接的批准。固定基础字段也受同一规则约束。explain 对允许字段输出按两审批 ID 元组字典序最小的合法证据，对拒绝输出排序首条显式拒绝，或逐字段区分缺一侧审批和机构不独立。explain 不打印实际字段值。

策略按单调代次原子发布，同一批可以追加审批、撤回和拒绝。撤回引用某审批，只从指定生效时间起去除其授权；代次内查询应保留此前的有效时间段。旧版查询仍忠实返回该版裁定，新的导出请求只能按当前代次发布。export 固定输入摘要、接收区、策略代次和请求 ID，以输入顺序流式写临时产物，只输出至少有一个获准字段的连接及获准字段；连接 ID 和原始五元组仅在对应字段获准时写入。临时产物须在本机可恢复：提交前发现代次变化，丢弃暂存产物并返回过时；将完整产物先写入不可变暂存路径，成功时在同一 SQLite 事务中核对代次并公布指向该产物的回执和摘要，读者只通过回执查看结果。相同请求 ID 和输入的重放返回原回执；同 ID 改输入拒绝。查询与导出期间不可读到半批策略或半成品。支持十万条连接，不逐地址展开 CIDR，不将全部连接载入内存。

交付可执行实现、README、规则与输入生成器和测试。用直接枚举审批对的独立参考实现核对一套小样本，并覆盖同一机构控制两区审批、某字段只有跨机构组合才通过、倒向流有单独规则、窄前缀拒绝覆盖宽前缀审批、端口和时间双边界、IPv6 等价拼写、撤回后发布中的竞态、故障后幂等恢复。verify 用绑定的策略代次和输入独立核对最终产物摘要与字段批准证据。
